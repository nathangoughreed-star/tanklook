## Decisions taken (flag to Nathan, none blocking)
1. **Start screen keeps SL1's three choices** (Nathan asked for Starter / Example today); v2's "Start New / Open Existing" is read as "New Setup / Open Existing" plus the starter gallery. New Setup now asks the habitat question; the DX5 shortcuts go.
2. **Keep from a proposal defaults to "exactly N"** (never silently changes a count), with the existing one-tap switch to "at least N" / "species only" (`FishKeep` in `ui/discover/logic.ts`).
3. **Freeze source**: unchecking a tab freezes the CHAMPION's values (before a champion: the working project); each card also has "Keep A's hardscape for now" which records that card as the source (spec 5.2).
4. **Like both** keeps the champion and records both as liked; **Like neither** keeps the champion, records a negative for both, and the next challenger is drawn from further away; **Skip** records nothing about taste (spec 3.4).
5. **First pair fast**: the first pair comes from the cheapest valid sources (DX2 `propose` on the current project, plus 2-4 Explore recipes from different worlds / families built on demand), never the whole pool; the pool fills in the background for later challengers.
6. **Preference model**: pairwise outcomes and reasons become `aspects.ts` events (winner +, loser -, reasons weighted x2; skip none); ranking only orders what the gate let through (Explore's existing separation).
7. **History**: every shown candidate, per project, browser-local, paged, cap 200 records with snapshots (favourites and champions never evicted; oldest unfavourited losers evicted first, and the index line stays with "picture and design no longer stored").
