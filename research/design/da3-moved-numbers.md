# DA3 part 2: Big Fish Showcase 75 -> 90 gal (2026-11-03)
`big-fish-showcase` `tags.minGallons` 75 -> 90. The catalogue has a 90 gal tank (`g90`, Aqueon 48.5 x 18.5 x 25.4 in; 90 gal is the smallest rated size at or above 90), so `minTank` picks it (was `g75`, 49 x 19.5 x 21.25 in glass).

| number | 75 gal (before) | 90 gal (after) |
|---|---|---|
| default / smallest tank | g75, 48.5 x 18.5 x 21.25 in | g90, 48.5 x 18.5 x 25.4 in (4 in taller, same footprint) |
| glass | 6 mm | 8 mm |
| Setup cost, one oscar, balanced build (`buildTotals`) | $1,066 | $927 |
| Upkeep, same build | $40.0 / mo | $43.6 / mo |
| Care time | 60 min / wk | 64 min / wk |

Why setup falls although the tank is bigger: the catalogue's 90 gal rows carry only one street price (Clear-For-Life, $1,259 - $1,900, not the plain glass tank), the Aqueon 90 gal has no listed price, so the plain tank is priced from the size curve; the 75 gal has street prices of $150 - $160. Flag for the weekly price sweep: an Aqueon / Marineland 90 gal glass price.
Other archetypes are unchanged (only this archetype's floor moved).
