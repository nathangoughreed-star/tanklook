# Climate batch 1: water temperature for 8 invertebrates/fish

Compiled 2026-10-19. F converted to C. O = page opened (fetched); S = search-result summary only. W = wild, C = captive recommendation. Many pages 403/429'd; those are noted. Seriously Fish has no profile for these species (catalogue stub). FishBase gave a figure only for royal gramma.

## 1. Cherry shrimp (Neocaridina davidi)
| Source | Type | Range C | URL |
|---|---|---|---|
| Modestfish (O) | C | 18-26; 24 speeds growth/breeding; no heater if room >18 | https://modestfish.com/cherry-shrimp |
| Aquatic Arts (O) | C | 17.8-25.5 | https://aquaticarts.com/products/wild-form-neocaridina-shrimp |
| CONICET experiment abstract (O) | C (lab) | 20, 24, 28 all >90% survival; males heavier at 20-24 than 28; "20-28 adequate", 20 hurts metabolism/reproduction | https://ri.conicet.gov.ar/handle/11336/180775 |
| Wikipedia (O) | W | no figures; invasive in thermally polluted waters (Japan, US, Poland, Germany) | https://en.wikipedia.org/wiki/Neocaridina_davidi |
| Aquarium Co-Op (O), Seriously Fish (O) | - | no temperature on page | |
| Hobby guides via search (S) | C | 18-26, 18-24, 18-27; one claims ceiling 26 (78F) not 27 | modestfish/2hraquarist/allfish2u |

| 2hraquarist (403) | | | |

Synthesis: comfortable **18-25**; tolerable **14-28** (short-term survival much wider: ~6 to 38, not recommended). Disagreement: upper limit 24/26/27 across guides; the lab data show 28 works but cuts male size. No wild field measurement found.
