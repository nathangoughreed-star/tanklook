# Guided card art

The Guided picture cards (src/ui/guided/) show a gradient + icon placeholder until a file with the slot's name exists here, then
show the picture automatically (a missing file just leaves the placeholder).

Names, sizes (.webp, 1200 x 750, under ~150 KB, subject centred: phones crop to 1:1) and what each picture shows:
**research/design/guided-art-brief.md**. Slots: `kind-freshwater`, `kind-saltwater`, `kind-terrarium`, `kind-paludarium`, `kind-any`,
`intent-animals`, `intent-look`, `intent-equipment`, `intent-ideas` (each `<name>.webp`).

AI art, not engine renders. Realistic and crisp, not cartoony.
